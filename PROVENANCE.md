# Provenance and chain of title

This records where llama-herd's code came from and who held the rights to release it, so the
project's licensing rests on a documented basis rather than assumption.

## Origin

llama-herd is an extraction of a weight-shared, multi-stream llama.cpp inference runtime developed
privately between **2026-07-14 and 2026-08-06** as part of a larger, unrelated private platform.
Only the runtime is extracted; the platform is not part of this project and remains private.

## Authorship

The imported code was authored **solely by Benjamin Goldman**. This is verifiable in the source
repository's history: 54 commits touching the runtime, all by one author, with the source repo's
`.mailmap` recording that the several git identities appearing in that history are the same
natural person and that no other person authored any commit.

No employer, contractor, joint author, or third-party contributor holds an interest in the
imported code, and it was not created under a work-made-for-hire arrangement.

## Effect on any later assignment

An Apache-2.0 grant is **irrevocable**. Once made, it survives any subsequent transfer of the
copyright: an assignee takes the copyright subject to the licence already granted, and cannot
withdraw it from anyone who has received the code.

Accordingly, if the drafted assignment is later executed, its schedule of assigned property should
record this Apache-2.0 release as an existing encumbrance on the extracted runtime. Omitting it
would make the schedule inaccurate.
